| Код | Требования                                                                                                                               | Комментарий  |
|-----|------------------------------------------------------------------------------------------------------------------------------------------|--------------|
| F   | Функциональные (Functionality)                                                                                                           |              |
| F1  | На сайте новый клиент видит список доступных депозитов с актуальными ставками.                                                           |              |
| F2  | Клиент может подать заявку на депозит на сайте, оставив свой номер телефона и Ф. И. О.                                                   |              |
| F3  | В интернет-банке клиент видит список доступных депозитов с актуальными ставками и персонализированные ставки лично для него.             |              | 
| F4  | В интернте-банке клиент может подать заявку на открытие депозита.                                                                        |              |
| F5  | Операцию подачи заявки на депозит клиент подтверждает с помощью СМС-кода.                                                                |              |
| F6  | Сотрудники бэк-офиса должны иметь возможность вести ставки по депозитам в АБС системе.                                                   |              |
| F7  | Сотрудники бэк-офиса должны иметь возможность подтверждать условия по депозитам в АБС системе.                                           |              |
| F8  | При одобрении условий депозита клиент получает СМС                                                                                       |              |
|-----|------------------------------------------------------------------------------------------------------------------------------------------|--------------|
| U   | Удобство использования (Usability)                                                                                                       |              |
| U1  | Интерфейс должен быть максимально удобным для клиента.                                                                                   |              |
| U2  | Сайт и интернет-банк должны быть разработаны в дизайн-системе компании (привычные цвета и брендированные элементы)                       |              |
|-----|------------------------------------------------------------------------------------------------------------------------------------------|--------------|
| R   | Надёжность (Reliability)                                                                                                                 |              |
| R1  | Все сервисы должны работать 24/7 с доступностью 99,9%                                                                                    |              |
| R2  | В случае сбоев в ЦОД все сервисы интернет-банка должны быть доступны и выдерживать требуемую нагрузку                                    |              |
|-----|------------------------------------------------------------------------------------------------------------------------------------------|--------------|
| P   | Производительность (Performance)                                                                                                         |              |
| P1  | Отклик по всем операциям должен занимать миллисекунды.                                                                                   |              |
| P2  | Возможность равномерного горизонтального масштабирования и распределения запросов между серверами, приложениями и ЦОД                    |              |
|-----|------------------------------------------------------------------------------------------------------------------------------------------|--------------|
| S   | Поддерживаемость (Supportability)                                                                                                        |              |
| S1  | Нужно предусмотреть разработку документации для дальнейшего расширения системы.                                                          |              |
|-----|------------------------------------------------------------------------------------------------------------------------------------------|--------------|
| +R  | + Ограничения (Restrictions)                                                                                                             |              |
| +R1 | Все данные с сайта и интернет-банка должны передаваться по защищенным соединениям                                                        |              |
| +R2 | При доработках во всех системах нужно как можно больше использовать технологии, которые уже есть в банке (БД MS SQL и Oracle)            |              |
| +R3 | Новые технологии (если необходимы) должны быть совместимы с существующими платформами разработки и должна быть экспертиза внутри банка   |              |
| +R4 | Если нужны очереди сообщений, то лучше использовать Kafka (текущая версия платформы интернет-банка несовместима с ней)                   |              |
| +R5 | Стоит подумать о переводе интернет-банка на микросервисную архитектуру                                                                   |              |
| +R6 | На данный момент АБС может масштабироваться только вертикально из-за своей базы данных                                                   |              |
|-----|------------------------------------------------------------------------------------------------------------------------------------------|--------------|
